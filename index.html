? Kostenlosen API-Schlüssel erstellen (1 Minute)
▼ Ausklappen
  1. Öffne die Website Google AI Studio und melde dich mit deinem normalen Google-Konto an.
  2. Klicke links oben auf die Schaltfläche „Get API key“.
  3. Wähle „Create API key“ (in a new project).
  4. Kopiere den generierten Schlüssel und füge ihn unten in das Eingabefeld ein.
💡 Hinweis: Der persönliche Zugriff über Google AI Studio ist im Free Tier komplett kostenlos und bietet mehr als genug Anfragen für die tägliche Unterrichtsvorbereitung.
